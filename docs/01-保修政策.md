# 保修政策

> 文档编号 KB-001 ｜ 版本 v3.2 ｜ 适用范围：家用空冰洗、厨电、热水器

## 1. 整机与核心部件保修期

1.1 空调整机保修 3 年，压缩机保修 6 年。
1.2 冰箱整机保修 1 年，压缩机保修 3 年。
1.3 洗衣机整机保修 3 年，电机保修 3 年。
1.4 热水器整机保修 1 年，内胆保修 5 年。
1.5 保修期自**安装完成日**起算；未安装的，自购机发票开具日起算。
1.6 无发票时，可按机身条码查询出厂日期，出厂日期 + 3 个月视为购机日。

## 2. 保修范围

2.1 保修期内，因产品自身质量问题导致的性能故障，免费维修，免收上门费与人工费。
2.2 保修期内更换的配件，按原保修期剩余时间计算，不重新起算。
2.3 换机后重新计算保修期，以换机完成日为起算日。

## 3. 不属于保修范围的情形

3.1 人为损坏：摔碰、进水、私自拆机、使用非原厂配件。
3.2 非家庭使用场景（商用、经营性使用）。
3.3 不可抗力：雷击、火灾、水灾、电压异常。
3.4 超出保修期的产品。
3.5 上述情形可提供有偿维修服务，收费标准见《收费与配件》。

## 4. 保修凭证

4.1 有效凭证为购机发票或电子订单号，二者任一即可。
4.2 发票遗失不影响保修权益，可凭订单号或机身条码核实。
4.3 发票遗失需补开的，联系购买渠道办理，售后网点不承担开票职责。
