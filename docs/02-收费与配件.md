# 收费与配件

> 文档编号 KB-002 ｜ 版本 v2.7

## 1. 上门费

1.1 保修期内、属保修范围的故障，**不收上门费**。
1.2 保修期内、经检测属人为损坏或非保修情形的，收取上门检测费 50 元。
1.3 超出保修期的，上门检测费 50 元；用户同意维修的，上门费并入维修费抵扣。
1.4 用户主动取消上门、且师傅尚未出发的，不收费。
1.5 师傅已出发后取消的，收取 30 元空跑费。

## 2. 人工费

2.1 简单维修（紧固、清洁、参数调整）：80 元/次。
2.2 常规维修（更换通用配件）：150 元/次。
2.3 复杂维修（拆机、系统管路、主板级）：300 元/次起，按检测结果报价。
2.4 报价须在施工前经用户确认，未经确认不得施工。

## 3. 常用配件参考价

3.1 空调压缩机：900-1600 元（按匹数）。
3.2 空调主板：400-700 元。
3.3 冰箱温控器：120 元。
3.4 洗衣机电机：350 元。
3.5 热水器内胆：600 元。
3.6 配件价格为参考区间，实际以网点出库价为准，差异不超过 15%。

## 4. 收费规则

4.1 一律通过官方小程序线上支付，**师傅不得收取现金或私人转账**。
4.2 维修完成后提供电子服务单，含故障描述、更换配件、费用明细、保修承诺。
4.3 同一故障 30 天内返修的，免收人工费。
4.4 配件更换后保修 90 天。
