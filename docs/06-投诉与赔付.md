# 投诉与赔付

> 文档编号 KB-006 ｜ 版本 v3.0

## 1. 投诉受理渠道

1.1 线上：官方小程序「服务单 - 投诉」入口。
1.2 电话：客服热线（7×24 小时）。
1.3 投诉须提供工单号，无工单号的按咨询处理。

## 2. 投诉分级与响应

2.1 一般投诉（服务态度、时效延误）：24 小时内首次回复，3 个工作日内闭环。
2.2 重大投诉（财产损失、人身安全、媒体曝光风险）：2 小时内升级至区域服务经理，24 小时内给出处理方案。
2.3 投诉处理过程中，同一工单由同一名专员跟进，避免重复沟通。

## 3. 师傅爽约处理

3.1 判定标准：未按约定时间上门，且未在上门前 2 小时通知改约。
3.2 处理动作：①记录爽约，扣减该网点服务分；②优先重新派单，24 小时内安排新师傅；③向用户致歉并说明改派时间。
3.3 因爽约导致用户产生实际损失的，按 3.4 赔付标准执行。
3.4 赔付：爽约一次，补偿 50 元服务券；同一工单爽约两次及以上，补偿 100 元服务券并可申请全额退还上门费。

## 4. 服务事故赔付

4.1 维修造成商品二次损坏：免费修复；无法修复的按折旧价赔付。
4.2 安装造成房屋或财物损坏：由承保方定损，7 个工作日内出结论。
4.3 赔付须走线上流程留痕，不得私下现金赔付。

## 5. 不予支持的诉求

5.1 无工单号、无法核实的口头投诉。
5.2 要求超出政策标准的赔付（如要求赔付新机）。
5.3 竞品价格比较类诉求：本公司不做比价，仅按自身服务标准答复。
