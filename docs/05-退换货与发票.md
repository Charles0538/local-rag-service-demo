# 退换货与发票

> 文档编号 KB-005 ｜ 版本 v2.4

## 1. 七天无理由退货

1.1 自签收次日起 7 日内，商品完好、不影响二次销售的，可无理由退货。
1.2 **已拆包装但未使用**、配件与说明书齐全的，仍可退；需承担退回运费。
1.3 已安装使用的商品，不适用无理由退货，按质量问题流程处理。
1.4 定制类、已剪裁类、个人卫生类商品不适用无理由退货。

## 2. 质量问题退换

2.1 签收 7 日内出现性能故障，可退货、换货或维修，用户自选其一。
2.2 签收 8-15 日内出现性能故障，可换货或维修。
2.3 签收 15 日后，按保修政策维修；同一故障维修 2 次仍未修复的，可申请换机。
2.4 退货需提供检测单，由售后网点出具，检测不收费。

## 3. 换货与退货时效

3.1 审核通过后 3 个工作日内安排取件或换新发出。
3.2 退款在商品入库验收后 1-3 个工作日原路退回。
3.3 分期付款订单退款，按支付渠道规则处理，可能分笔退回。

## 4. 发票

4.1 电子发票在订单完成后 24 小时内开具，可在订单页下载。
4.2 发票遗失：电子发票可重新下载，不涉及补开；纸质发票遗失可申请开票记录复印件。
4.3 发票抬头、税号填错的，可在开票后 90 日内申请重开一次。
4.4 保修**不以发票为唯一凭证**，发票遗失仍可凭订单号或机身条码享受保修。
4.5 退票：发生退货的，需先完成发票冲红，再办理退款。
